開発レビュー

「世界 → 工場 → 回転軸」の入口を作っている本番α版です。現在は、3D世界で最初の工場を建て、次に必要な部品が回転軸だと分かるところまで実装しています。

現在のゲーム画面

実装済み

  • スマートフォン縦画面向け3Dジオラマ
  • 候補地の選択と最初の工場建設
  • ドラッグによるカメラ移動
  • ピンチ／ホイールによるズーム
  • 建設後の次需要「回転軸」の表示

現在の進行
