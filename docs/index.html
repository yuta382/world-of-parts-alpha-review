現在のゲーム画面

実装済み

  • スマートフォン縦画面向け3Dジオラマ
  • 候補地の選択と最初の工場建設
  • ドラッグによるカメラ移動
  • ピンチ／ホイールによるズーム
  • 建設後の次需要「回転軸」の表示
  • 給水ポンプ用回転軸の受注表示
  • 高速加工または精密加工を一つ選び、検査を必要なら追加
  • 加工方法→任意検査の順序確認と加工直前の準備状態
  • 名前空間付きIDによる部品・機械・産業・街のコンテンツ参照
